Support

Questions and problems: GitHub Issues.

Requirements

  • macOS 26 or later, or iOS / iPadOS 26 or later
  • An Apple translation language pack, downloaded from the app

Earlier versions of the operating system are not supported: the system capability that makes on-device translation available to the extension arrives in 26.

First-time setup

  1. Open the QuickGlot app.
  2. Choose the language you read and the language you want it translated into, then press Download. Each pack is downloaded once and then works offline.
  3. Turn the extension on in Safari.
    • macOS: Safari → Settings → Extensions → QuickGlot
    • iOS / iPadOS: Settings → Apps → Safari → Extensions → QuickGlot
  4. Allow QuickGlot to access the sites you want to use it on.
  5. Click the QuickGlot icon in the Safari toolbar and pick the language to translate into.

Using it

  • macOS: select text with the mouse and the translation appears where you selected.
  • iOS / iPadOS: select text, then tap the button that appears.

The panel stays with the sentence it translated. Click outside it or press Esc to dismiss it.

Common questions

Nothing appears when I select text

  • Check that the extension is enabled and allowed on that site in Safari's settings.
  • Tabs that were already open when you enabled the extension need to be reloaded.
  • Selections inside text fields, search boxes, and other editable areas are ignored on purpose.

Nothing happens on text I can already read

That is intended. If the selection is already in your target language, nothing is shown. With the target pinned to a language, pages in that language stay quiet.

It says the language pack is not downloaded

Open the QuickGlot app and download that language pair. Wait for the system download to finish before dismissing the sheet — closing it early can leave the pack unfinished. Press Recheck in the app to re-read the status.

A single word sometimes does not translate

Very short selections are hard to identify a language for. Rather than translate them as the wrong language, QuickGlot shows nothing. Selecting the surrounding sentence works.

Which languages are supported?

Whatever Apple's on-device translation supports. Click the toolbar icon to see the list actually available on your device.
