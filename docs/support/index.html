요구 사항

  • macOS 26 이상 또는 iOS / iPadOS 26 이상
  • Apple 번역 언어팩 (앱에서 내려받습니다)

이전 버전 OS 에서는 동작하지 않습니다. 기기 안에서 번역하는 데 필요한 시스템 기능이 26 부터 제공되기 때문입니다.

처음 설정하기

  1. QuickGlot 앱을 실행합니다.
  2. 읽으려는 언어와 번역받을 언어를 고르고 Download 를 눌러 언어팩을 내려받습니다. 한 번만 받으면 이후에는 오프라인에서도 동작합니다.
  3. Safari 에서 확장을 켭니다.
    • macOS: Safari → 설정 → 확장 프로그램 → QuickGlot
    • iOS / iPadOS: 설정 → 앱 → Safari → 확장 프로그램 → QuickGlot
  4. QuickGlot 에 사이트 접근을 허용합니다.
  5. Safari 툴바의 QuickGlot 아이콘을 눌러 번역받을 언어를 고릅니다.

사용하기

  • macOS: 텍스트를 드래그해 선택하면 그 자리에 번역이 뜹니다.
  • iOS / iPadOS: 텍스트를 선택하면 버튼이 나타나고, 누르면 번역이 뜹니다.

번역 창은 선택한 문장 옆에 남아 있으며, 바깥을 누르거나 Esc 를 누르면 닫힙니다.

자주 묻는 문제

번역 창이 뜨지 않습니다

  • Safari 설정에서 확장이 켜져 있고, 해당 사이트에 접근이 허용돼 있는지 확인해 주세요.
  • 확장을 켠 뒤 이미 열려 있던 탭은 새로고침해야 동작합니다.
  • 입력란·검색창처럼 글자를 입력할 수 있는 영역 안의 선택은 의도적으로 무시합니다.

이미 읽을 수 있는 언어인데 아무 반응이 없습니다

정상입니다. 선택한 글이 이미 번역 대상 언어이면 아무것도 표시하지 않습니다. 번역받을 언어를 한국어로 고정해 두었다면 한국어 페이지에서는 창이 뜨지 않습니다.

"언어팩을 내려받지 않았습니다" 라고 나옵니다

QuickGlot 앱을 열어 해당 언어 쌍을 내려받아 주세요. 시스템 다운로드 창에서 완료될 때까지 기다린 뒤 닫아야 합니다. 창을 미리 닫으면 설치가 끝나지 않을 수 있으며, 이때는 앱에서 Recheck 를 눌러 상태를 다시 확인할 수 있습니다.

단어 하나를 선택하면 번역되지 않을 때가 있습니다

너무 짧은 문장은 어떤 언어인지 판정하기 어려워, 잘못된 언어로 번역하는 대신 표시하지 않습니다. 단어가 포함된 문장을 함께 선택하면 번역됩니다.

지원하는 언어가 궁금합니다

Apple 의 온디바이스 번역이 지원하는 언어를 그대로 따릅니다. 툴바 아이콘을 누르면 이 기기에서 실제로 사용할 수 있는 목록이 표시됩니다.
