# QuickGlot

**Safari에서 문장을 선택하고, 그 자리에서 번역하세요.**

QuickGlot은 Mac · iPhone · iPad용 Safari 번역 확장 프로그램입니다. Apple의 온디바이스 번역을 사용해 기기 안에서 처리합니다. 언어팩을 한 번 내려받으면 오프라인에서도 사용할 수 있고, 계정이나 API 키는 필요하지 않습니다.

[**App Store에서 다운로드**](https://apps.apple.com/kr/app/quickglot/id6807894387) · [사용 도움말](https://no1joon.github.io/quickglot/support/) · [문의·오류 신고](https://github.com/No1Joon/quickglot/issues)

## 이렇게 사용하세요

| 기기 | 번역하는 방법 |
| --- | --- |
| **Mac** | 웹페이지의 텍스트를 드래그해 선택하면 번역이 나타납니다. |
| **iPhone · iPad** | 텍스트를 선택하고, 선택 영역 근처의 **QuickGlot 버튼**을 누릅니다. |

번역은 선택한 문장 옆에 표시됩니다. 번역 창 바깥을 누르면 닫힙니다.

## 처음 한 번만 설정하세요

**macOS 26 이상 또는 iOS / iPadOS 26 이상**과 Safari가 필요합니다.

1. **앱 설치** — App Store에서 QuickGlot을 설치하고 엽니다.
2. **언어팩 다운로드** — 읽을 언어와 번역받을 언어를 고른 뒤 **Download**를 누릅니다. 처음 다운로드할 때는 인터넷 연결이 필요합니다.
3. **Safari 확장 켜기** — 아래 설정에서 QuickGlot을 켜고 번역할 사이트에 대한 접근을 허용합니다.
4. **번역 언어 선택** — Safari 툴바의 QuickGlot에서 번역받을 언어를 고릅니다.

| 기기 | 확장 프로그램 설정 위치 |
| --- | --- |
| **Mac** | Safari → 설정 → 확장 프로그램 → QuickGlot |
| **iPhone · iPad** | 설정 → 앱 → Safari → 확장 프로그램 → QuickGlot |

> 확장을 켜기 전에 열어 둔 웹페이지는 새로고침해 주세요.

## 번역이 나타나지 않나요?

- **확장과 사이트 권한을 확인하세요.** Safari에서 QuickGlot이 켜져 있고 현재 사이트에 접근할 수 있어야 합니다.
- **언어팩을 확인하세요.** 다운로드 안내가 나오면 QuickGlot 앱을 열어 해당 언어팩을 내려받아 주세요.
- **문장 전체를 선택해 보세요.** 짧은 단어는 언어를 구분하기 어려울 수 있습니다.
- **이미 대상 언어인 글은 번역 창을 띄우지 않습니다.** 입력란이나 검색창 안의 텍스트도 번역하지 않습니다.

자세한 안내는 [고객 지원](https://no1joon.github.io/quickglot/support/)에서 확인할 수 있습니다.

## 개인정보

선택한 텍스트와 번역 결과를 외부 서버로 전송하지 않습니다. QuickGlot은 광고나 이용 분석을 위한 데이터를 수집하지 않습니다. 번역 대상 언어 설정은 기기에 저장하고, 최근 번역은 반복 처리를 줄이기 위해 메모리에 임시 보관합니다.
